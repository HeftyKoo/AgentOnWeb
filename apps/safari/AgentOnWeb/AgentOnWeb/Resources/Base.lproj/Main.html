AgentOnWeb

Your native coding agent, on the web.

▶

Try it now — no setup needed

Explore populated sample conversations, tool results, a scratchpad, and the real presentation controls. Works offline without DSH, an account, or an API key.

1

Enable in Safari

Enable AgentOnWeb in Safari and allow the websites where you want to use it.

The extension is enabled. Allow website access in Safari to show the page dock.

The extension is off. Enable it in Safari and allow website access.

2

Start your local workspace

This edition uses DeepSeek Harness 0.1.2-alpha.3. Install Node.js 22.19 or newer and DSH, then add the plugin to its Web profile:

dsh plugin --profile web add @agentonweb/dsh-surface@0.1.0

Start or restart the workspace and keep it running:

dsh web

Configure your own model credentials in DSH. Provider usage may incur charges.

3

Connect on a website

Open a normal website in Safari. Click the AgentOnWeb toolbar icon or page dock, choose Connect, and approve Allow connection in DSH.

Chill gives you a translucent workspace. Focus keeps it opaque. Watch leaves the website fully interactive.

Double-tap Option in Chill to switch interaction between the page and DSH.
